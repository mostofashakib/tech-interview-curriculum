Data structures, algorithms, and coding-round practice.

## Suggested order

1. Skim `references/algorithm-cheat-sheet.pdf` to find your weak areas
2. Implement from `implementations/` topics until you can write each from scratch
3. Grind `practice-problems/company/<target company>/`
4. Use `study-plan/` if you want structure over months rather than weeks
