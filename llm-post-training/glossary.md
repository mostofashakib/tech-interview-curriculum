# Glossary

> From [Post-Training LLMs](https://www.mostofashakib.com/blog/post-training-llms).
> The vocabulary you need before the RL sections make sense. If you can't define
> these cold, start here.

**Activation function** — the non-linearity in a neural network. Without it, any
stack of layers collapses into a single linear transformation.

**Policy (π)** — the LLM itself, viewed as a decision-maker. Its weights define a
distribution over next tokens. In RL notation `π_θ` is the model being trained,
`π_ref` is the frozen reference (usually the SFT checkpoint).

**Value function** — an estimate of the expected future reward from the current
state. In PPO this is a separate model (the critic) that predicts how good a
partial generation is, used as a baseline to reduce gradient variance.

**Trajectory** — a full sequence: the tokens generated for a prompt, or the whole
execution path of an agent including tool calls. What gets scored in RL.

**KL divergence** — a measure of how far one distribution has drifted from
another. In post-training it measures how far the trained policy has moved from
the reference model. The leash that stops RL from destroying the model in
pursuit of reward.

**Fisher Information Matrix** — a second-order (curvature) quantity describing how
sensitive the output distribution is to each parameter. TRPO uses it to take the
largest step that stays inside a trust region. Powerful, and expensive enough
that PPO replaced it with a cheap first-order approximation.

## Adjacent terms worth having ready

**Reward model (RM)** — a learned scalar scorer, trained on human preference pairs,
that stands in for a human rater during RL.

**Advantage (A)** — how much better an action was than expected. `reward − baseline`.
The baseline is a value model in PPO, and the group mean in GRPO.

**Rollout** — generating samples from the current policy to score and learn from.
The expensive part of online RL.

**On-policy vs off-policy** — whether you learn from data generated by the current
policy (PPO, GRPO) or from a fixed dataset generated earlier (DPO).

**Behavioral cloning** — supervised imitation of demonstrations. What SFT is.

**Reward hacking** — the policy finds a way to score high that doesn't reflect the
intent behind the reward. Goodhart's law with a gradient.

**Catastrophic forgetting** — the model masters the new objective and loses
capabilities it previously had.
