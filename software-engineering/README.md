## How to use this route

System design is the highest-variance round at senior level — start there and
give it the most time. `cs-fundamentals/` is mostly recall and rewards spaced
review over long sessions; keep the `links.txt` files, they point at sources
better than the PDFs. Hit `languages/` only for the stack the role actually
uses.
